# SEED 인터페이스

NAS에서 직접 접속하는 독립 React 앱입니다. 기존 개요·작업·데이터·학습·설정 페이지의 구성과 디자인을 유지하며 `Interface ↔ RAG (Pre ↔ Post)` API를 연결합니다. Sites 또는 GPT 서비스에 의존하지 않습니다.

## 실행

Node.js와 npm이 설치된 환경에서:

```powershell
cd Interface
npm.cmd install
npm.cmd run dev -- --port 5173
```

브라우저에서 http://localhost:5173 에 접속합니다. macOS/Linux에서는 `npm.cmd` 대신 `npm`을 사용합니다.

RAG 서버도 별도 실행해야 합니다. 실행 절차는 [RAG README](../RAG/README.md)를 참고하세요. 개발 서버의 `/api` 요청은 `http://127.0.0.1:8000`으로 프록시합니다. 개발 서버는 기본적으로 현재 PC의 loopback에만 바인딩합니다. 운영 시 정적 빌드와 API를 NAS의 동일 출처에서 제공합니다.

## 화면

- **개요**: 실제 문서·검색 청크·모델·학습 지표, 서버 활동, 색인 현황
- **작업**: 작성·검토·리팩토링·테스트 모드, 실제 RAG 검색·생성, 근거, 스트리밍·중단, 서버 기록, 코드 복사
- **데이터**: 실제 원문 업로드, 검색·상태 필터, 소스 수집·중지, 문서·청크 검토, 검색 승인·제외
- **학습**: 실제 서버 스텝 기반 진행률, 연결 상태, 학습 요청/제어, 서버 기록
- **마이페이지**: 상단 프로필 또는 워크스페이스에서 열기, 이름 변경, 테마 전환, 환경 설정 이동
- **설정**: 화면 테마(라이트·다크·시스템), 서버 설정, 추론 연결 검사, 로컬 임베딩·토큰 예산, 수집 예약, 백업, 학습 후보 검토·스냅샷 내보내기

## 현재 구현 범위

파일·소스·대화·설정은 RAG 서버가 원본입니다. 기존 브라우저에 있던 메타데이터나 데모 응답을 실제 자료로 자동 이관하지 않습니다. 페이지의 데모 응답 타이머는 실제 요청으로 대체했습니다. 서버 미연결·마지막 값 갱신 중단·모델 미연결을 구분하며, 관측하지 못한 수치를 임의로 만들지 않습니다.

JSON/JSONL 외 UTF-8 텍스트·코드 파일도 업로드할 수 있습니다. 원문은 서버에 전송·저장되며 서버가 검증·정제·청킹·색인합니다. 파일당 10 MiB, 요청 전체 25 MiB를 넘을 수 없습니다. 검색 승인과 학습 이용 승인은 별도입니다. 비밀정보 격리는 단순 검색 승인으로 우회할 수 없습니다.

작업 요청은 RAG 검색을 기본으로 사용합니다. 실제 생성은 별도로 설치·연결한 추론 서버와 정확한 토큰 예산을 위한 tokenizer가 필요합니다. 연결 전에도 검색 근거를 확인할 수 있으며, 고정 데모 답변을 대신 제공하지 않습니다. 코드·테스트는 자동 실행하지 않습니다.

학습 화면은 동일 출처의 RAG 학습 게이트웨이를 통해 실제 학습 서버 응답만 표시합니다. `LLM` 폴더의 훈련 엔진은 이번 연결 범위에 포함하지 않습니다. 모델 설치·가중치 학습·자동 모델 교체는 수행하지 않습니다. 상세 계약은 `TRAINING_API.md`를 참고하세요. 테마와 최근 작업 모드 같은 화면 취향만 브라우저에 저장하며, 비밀번호·토큰을 localStorage에 저장하지 않습니다.

모델 후보는 설치 목록과 다릅니다. DS923+ 기본 4 GB RAM을 기준으로 0.5B·1.5B 후보를 표시하고 3B는 8 GB 이상 설정 시 검토 후보로 제시합니다. 이는 NAS 실측·훈련 호환성 보장이 아닙니다.

## 프로덕션 빌드

```powershell
npm.cmd run build
```

`dist` 폴더에 생성된 정적 파일을 NAS의 정적 웹 서버에서 제공할 수 있습니다. 현재 실행한 Vite 개발 서버는 로컬 미리보기용입니다. Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.

## 검증

```powershell
node --test src/rag-api.test.js src/training-api.test.js
npm.cmd run build
```

어댑터 테스트는 CSRF·멱등 키, 서버 오류, 실제 multipart 전달, UTF-8 SSE 경계, 지표 단위 분리와 기존 실제 학습 스텝 계약을 검증합니다.

## DS923+ 모델 후보

Qwen2.5-Coder Q4_K_M 0.5B(398 MB), 1.5B(986 MB), 3B(1.9 GB)를 표시합니다. 파일 크기는 실행 RAM과 다릅니다. 기본 RAM·DSM 사용량·컨텍스트·동시 로드 수에 따라 운영 가능 여부와 지연이 달라집니다. 기준 RAM은 사용자 입력이며 실제 NAS 감지값이 아닙니다. 학습·병합 가능 여부를 의미하지 않습니다.

서로 다른 크기의 모델은 텐서 크기가 달라 직접 합산·원소별 곱으로 병합할 수 없습니다. 같은 베이스·텐서 모양·토크나이저를 확인하고, 원본 가중치나 어댑터로 병합 방법을 별도로 검증해야 합니다. 가중치 합·곱 자체는 자동 학습이나 성능 향상을 보장하지 않습니다.

사양·모델 파일 크기 출처는 화면의 공식 사양 및 모델 정보 링크에 연결했습니다. 상세 근거는 `MODEL_CANDIDATES.md`를 참고하세요.
